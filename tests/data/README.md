# Local Test Data

This folder is reserved for validation data used during development.

The large experiment files are intentionally **not** committed to GitHub.

Expected local structure:

- `Real_Experiment/`
- `Simulated_Experiment/`
- any future `short_experiment/` validation set

Use these files for:

- local regression checks
- MATLAB vs Python comparisons
- debugging and figure generation

Only lightweight documentation files are tracked in the repository.
